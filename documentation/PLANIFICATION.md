## choix technologiques
### gestion des données:
Fichier JSON local (plus simple à gérer, moins de problèmes techniques)
### animations:
CSS pur et scroll-driven animation CSS (plus simple à gérer, moins de plugins)
### structure de navigation:
one-pager avec pages individuelles pour chaque projet
### Hébergement:
Github pages (aucun server à gérer, pas de risque de briser le site après une update)

## Idées d'animations
Animations simples pour ne pas distraire des projets (changement de couleurs en hover sur les boutons).
Animations en scroll subtiles sur les éléments décoratifs en background.
